`docker compose version` resolves (`v5.1.1`), so the CLI is installed —

## 3. Wet-run commands a human operator must execute

The drill below assumes a workstation with Docker Desktop running,
`pg_dump`/`pg_restore` 16 on PATH (alpine container's psql tools are
fine via `docker exec`), `tsx`, and `pnpm` installed.

```bash
# --- Step 0: Ensure docker-compose Postgres is up -------------------------
docker compose up -d postgres
docker ps --filter "name=spv-postgres" --format "{{.Names}} {{.Status}}"
# Expect: spv-postgres Up X seconds (healthy)

# --- Step 1: Capture current state to a portable dump --------------------
TS=$(date -u +%Y%m%dT%H%M%SZ)
DUMP=/tmp/drill-${TS}.pgdump
docker exec spv-postgres pg_dump \
  --format=custom --compress=9 --no-owner --no-acl \
  postgresql://spv:spv_dev_password@localhost:5432/spv_dev \
  > "$DUMP"
ls -lh "$DUMP"
# Expect: a non-zero binary file (custom format starts with 'PGDMP').

# --- Step 2: Create a throwaway DB ----------------------------------------
DRILL_DB="spv_drill_${TS}"
docker exec spv-postgres psql -U spv -d postgres -c "CREATE DATABASE \"${DRILL_DB}\";"
# Expect: CREATE DATABASE

# --- Step 3: Restore into the throwaway ----------------------------------
# Copy the dump into the container so pg_restore inside it can read it:
docker cp "$DUMP" "spv-postgres:/tmp/drill.pgdump"

START_EPOCH=$(date -u +%s)
docker exec spv-postgres pg_restore \
  --clean --if-exists --format=custom --no-owner --no-acl --exit-on-error \
  --dbname="postgresql://spv:spv_dev_password@localhost:5432/${DRILL_DB}" \
  /tmp/drill.pgdump
# Expect: exit 0. Time it (next step uses the same START_EPOCH).

# --- Step 4: Run the verifier against the throwaway ----------------------
cd apps/backend
DATABASE_URL="postgresql://spv:spv_dev_password@localhost:7654/${DRILL_DB}" \
  pnpm exec tsx ../../infra/scripts/verify-restore.ts
END_EPOCH=$(date -u +%s)
echo "RTO measured: $((END_EPOCH - START_EPOCH))s"
# Expect (verify-restore stdout, abridged):
#   verify-restore: starting
#     node=vXX.X.X pid=NNN
#     DATABASE_URL host=localhost:7654
#
#   === Row counts ===
#     ✓ tenants: count=N (min=1)
#     ✓ users: count=N (min=1)
#     ✓ students: count=N (min=1)
#     ✓ payments: count=N (min=0)
#     ✓ fee_plans: count=N (min=0)
#     ✓ audit_logs: count=N (min=0)
#
#   === Audit hash chain ===
#     ✓ tenant=<uuid> broken_count=0
#     ... (one line per tenant)
#
#   === Summary ===
#     PASS — no anomalies
# Expect: exit code 0. RTO < 60 minutes (target < 5 min for the dev dataset).

# --- Step 5: Tear down ---------------------------------------------------
docker exec spv-postgres psql -U spv -d postgres -c "DROP DATABASE \"${DRILL_DB}\";"
rm -f "$DUMP"
```

The operator then updates this file in-place: change the **Status** banner
from `DRY-RUN` to the wet date, fill in §4 with the actual stdout/stderr,
and record the measured RTO and any anomalies in §5.
